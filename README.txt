NEET Tracker 360 — Installable Android-style version

WHAT THIS IS
A Progressive Web App (PWA). It behaves like an Android app: it has an app icon,
standalone window, offline cache, mobile bottom navigation, and local saved progress.

IMPORTANT
For Chrome to offer "Install app", the files must be served from HTTPS (or localhost).
Opening index.html directly as a file may let you use the tracker but will not enable
full PWA installation.

EASIEST USE
1. Extract this ZIP.
2. Put the folder on an HTTPS static host (for example GitHub Pages, Cloudflare Pages,
   Netlify, or another static host).
3. Open the HTTPS page in Chrome on Android.
4. Tap the Install button inside the app, or Chrome menu -> Add to Home screen / Install app.
5. Launch it from the home-screen icon.

The app stores tracker data locally in the browser/device.

Included:
- index.html
- manifest.json
- sw.js
- icon-192.png
- icon-512.png

login systems, or proprietary course content.
